## Exact numerical scope tested

`tests/test_r_parity.py` passes identical 18×24 synthetic matrix and identical C/S initial factors to the active R functions. It checks singular values, unconstrained and NNLS C, soft closure, NNLS and mixed-sign S, and standard two-component ALS. SVD sign and component scaling are not compared directly because factorization is nonunique; model and fit diagnostics are. Cross-language broadening test measures and asserts the known shift rather than pretending parity. Unit tests cover import layouts, decimal comma, compression, averaging/tiling, baseline, selection, SVD reconstruction, ALS reconstruction, normalized fixed spectrum, and two-component rotation reconstruction/positivity. The notebook is executed separately. Direct `rotAmb2` parity is blocked by the R matrix class error described above.

`tests/test_kinetics.py` additionally checks parser roundtrip, physical time in multiple experiments, analytic A → B → C and A + B → C concentration curves, weighted/global fitting, fitted rate and residual reconstruction. The R parity test calls active `kinet` and `model` functions on a synthetic A → B matrix: concentration maximum absolute difference `4.51e-7`, model difference `4.71e-7`, with `rtol=2e-5`, `atol=2e-6`. On deterministic noisy input, R/Python rate estimates are `0.7001585/0.7001586` with an absolute gate of `0.01`. Synthetic `.Rda` project and selection files generated by R are imported into Python and their matrix, axes, physical times, and masks checked. The Python application never uses R during analysis or `.Rda` import.

No comparison on experimental or patient data was made. Passing synthetic benchmarks do not establish equivalence for arbitrary reaction networks, constraints, noise models, posterior uncertainty, or input formats.
